# 簡報大綱交接給 Claude 的製作說明

請分別依三份 Markdown 大綱製作三個繁體中文簡報：

1. `01-教學應用-簡報大綱.md`：教學 A、B 班共用同一簡報。
2. `02-行政應用一-簡報大綱.md`：台灣高中教務處課發會／校訂選修及學務活動工作流。
3. `03-行政應用二-簡報大綱.md`：問卷、設備、報告簡報及多步驟行政流程。

保留每頁的標題、重點和講者備註。視覺需區分來源文件、Agent 草稿、待確認和核定資訊；不得編造 Codex 介面截圖、實際外掛名稱、課綱條文或真實校務資料。課綱來源用官方網站入口作為講師核對提示，不把情境摘要排版成法規引文。全程繁體中文；所有校務人物和紀錄視為合成案例。
