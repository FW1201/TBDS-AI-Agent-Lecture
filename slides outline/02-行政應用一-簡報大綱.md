# AI Agent 行政自動化思維應用初探（一）｜簡報內容大綱

> 可直接交給 Claude 生成簡報。請把「講者備註／操作」放入備註頁。建議 3 小時、22 頁。以台灣高中教務處課發會、校訂選修及學務活動為情境，所有校務資料均為合成素材。

## 投影片 1｜封面

**投影片文字**：AI Agent 行政自動化思維應用初探（一）｜從散落校務資料到可覆核的文件與表格｜Codex 實作課

**講者備註／操作**：今天的重點是讓 Agent 整理和編輯工作檔案，先產生草稿和追蹤表，不直接執行正式校務動作。

## 投影片 2｜行政工作為何適合從 Agent 開始

**投影片文字**
- 重複整理：課發會提案、校訂選修意向、家長通知和活動分工
- 資料散落：郵件、附件、試算表、舊版範本
- 人工風險：漏掉期限、責任人、版本差異
- Agent 可協助整理；人員核定政策與責任

**講者備註／操作**：請學員說出最耗時的一項整理工作，不分享真實個資或機密內容。

## 投影片 3｜今天的成果

**投影片文字**
- 建立行政案例 workspace
- 使用 GitHub 資源包中的 skill/context
- 讓 Agent 盤點散亂資料，再編輯文件和工作表
- 完成課發會摘要、校訂選修通知或成果交流日計畫其中一個流程
- 建立可檢查的交付標準

**講者備註／操作**：學生資料包含多種檔案、草稿和矛盾資訊；學員需先讓 Agent 找出問題。

## 投影片 4｜Prompt／Context／Harness 套用到行政任務

**投影片文字**
- Prompt：任務、對象、期限、輸出格式
- Context：核准政策、會議來源、表單範本、行政用語
- Harness：workspace、讀寫範圍、skill、工具與覆核點
- 原則：Agent 草擬，承辦人核定

**講者備註／操作**：拿一則模糊「幫我整理會議」指令，補成具體任務卡。

## 投影片 5｜Agent 可以操作哪些檔案

**投影片文字**
- 讀取：文件、郵件、PDF、CSV、試算表
- 整理：分類、比對、擷取欄位、標記疑點
- 編輯：建立副本、產出草稿、更新指定工作表
- 檢查：列來源、變更、缺漏和驗收方式

**講者備註／操作**：依實際 Codex/檔案能力展示；強調任何批次移動或覆寫前先提出計畫。

## 投影片 6｜下載 GitHub 行政資源包

**投影片文字**
- 把指定 repo 下載／clone 到 resources/inbox
- 記錄來源 URL、版本和日期
- 盤點 skill、context、範本及依賴
- 不把帳密或真實校務資料放入資源包

**講者備註／操作**：使用已匯入的 `FW1201/tw-edu-skills` v5.0.1 副本，依 manifest 核對 commit 和 MIT 授權；檢視 skill 的用途與輸入，不執行安裝器。

## 投影片 7｜將資源整理進 workspace

**投影片文字**
- resources/inbox：保留原始下載
- skills：Agent 執行工作的流程卡
- context：規定、詞彙、背景和資料字典
- projects/案例/input：本次原始材料
- projects/案例/output：Agent 草稿及檢核結果

**講者備註／操作**：帶學員認識目錄用途；不要求所有來源檔案先手動整理好。

## 投影片 8｜案例包：台灣高中校務資料為何會亂

**投影片文字**
- 多個附件和版本，檔名不一致
- 課發會提案、選修意向調查、學務活動通知散落
- 草稿和核定場地文件的日期／地點說法不同
- 表格有重複列、空白值和格式混用
- Agent 需指出衝突，不可猜一個答案

**講者備註／操作**：展示資料包索引但不揭示答案；請學員預測要先問 Agent 什麼。

## 投影片 9｜第一步：要求 Agent 做檔案盤點

**投影片文字**
- 列檔名、格式、日期和摘要
- 標出可能重複、過期或互相矛盾的檔案
- 說明資料來源與不確定處
- 先提出分類方案，不立刻改動原始檔

**講者備註／操作**：實際指派 Agent 盤點一個案例資料夾，展示它產生的 inventory 和問題清單。

## 投影片 10｜案例 A1：課發會校訂選修意向調查通知

**投影片文字**
- 輸入：課發會提案、會議紀錄草稿、意向調查表、舊通知
- 使用：校務公告 skill + 選課流程 context
- 輸出：意向調查通知草稿、缺漏欄位、待教務處確認問題
- 驗收：不得把意向調查說成正式選課或保證開課

**講者備註／操作**：表格有重複回覆、舊課名和空白志願；讓 Agent 先列出疑點，不可自行決定正式選課日或合併課名。

## 投影片 11｜公告任務的 Prompt 拆解

**投影片文字**
- 任務：寫一份校訂選修意向調查通知草稿
- Context：只使用已確認課程名稱和校內流程
- 格式：調查目的、候選課程、截止時間、填答方式、聯絡角色
- 邊界：與正式選課區隔；不新增規則；不寄送；標記待核定欄位

**講者備註／操作**：用簡報中範例 Prompt 演示「先問矛盾、後產草稿」的兩階段操作。

## 投影片 12｜案例 A2：課發會紀錄和行動追蹤

**投影片文字**
- 輸入：課程發展委員會提案、會議草稿、收件匣討論和意向表
- 輸出：討論、暫議、已決議、承辦角色、期限、未決事項
- 把敘述文字轉為可篩選的表格欄位
- 不推測未明確指定的責任人或決議

**講者備註／操作**：要求 Agent 對每筆決議引用來源；草稿中的開課容量不得升格為正式決議，不確定項目放入待確認欄。

## 投影片 13｜Sheets 工作表要能追溯

**投影片文字**
- 欄位定義清楚：事項、來源、負責角色、期限、狀態
- 日期使用一致格式
- 保留原始描述與整理後欄位的對照
- 重複紀錄先標示，不直接刪除

**講者備註／操作**：展示追蹤表的欄位設計及簡單篩選；說明不要讓 Agent 無聲合併衝突紀錄。

## 投影片 14｜案例 A3：校訂課程成果交流日

**投影片文字**
- 比對成果交流日計畫、家長通知、會議補充和場地核定
- 用文件呈現計畫，用工作表追蹤教務／學務／總務角色任務
- 標出作品展示授權、攝影告知和無障礙動線待辦
- 不把核定場地誤當成整體活動流程已核准

**講者備註／操作**：示範 2026-11-28 場地核定 PDF 與未核定家長通知的差異。Agent 產出計畫草案和工作表，不發送通知、不代表校方核准。

## 投影片 15｜Doc 與 Sheets 如何一起工作

**投影片文字**
- Document：說明目的、流程、決定和待辦
- Sheets：追蹤欄位、狀態、期限和數量
- 相同事項使用可對照的 ID／名稱
- 兩種產出都標記來源與未確認欄位

**講者備註／操作**：展示一份會議紀錄和其追蹤工作表如何互相對應。

## 投影片 16｜讓 Agent 建立草稿而不破壞原檔

**投影片文字**
- 指定可讀來源和唯一輸出資料夾
- 明確要求建立新檔，不覆蓋來源
- 需要大量整理時先列操作清單
- 完成後列出新增／修改檔案

**講者備註／操作**：演示對 Agent 說明可寫入範圍；比較前後檔案清單。

## 投影片 17｜Connectors／MCP 的使用判斷

**投影片文字**
- 先確認是否需要連接外部服務
- 確認授權帳號、資料範圍和操作權限
- 先用唯讀或草稿功能熟悉流程
- 未開通時使用課程提供的本地模擬檔

**講者備註／操作**：只演示已核准連接器；不將未核准的校務資料上傳外部服務。

## 投影片 18｜Skill：讓可靠步驟可重複

**投影片文字**
- 讀 skill 的輸入、步驟、輸出和檢查
- 檢查資源來源和版本
- 在任務中指定使用哪個 skill
- 任務 context 不同，結果仍需人工覆核

**講者備註／操作**：讓 Agent 回報使用的 skill 和套用步驟，學員比對是否有照做。

## 投影片 19｜人工覆核的五個問題

**投影片文字**
- 有沒有把意見誤寫成決議？
- 日期、對象、金額和地點是否有來源？
- 有沒有重複、遺漏或互相矛盾的資料？
- 哪些欄位是推論或待確認？
- 有沒有不應外傳的內容？

**講者備註／操作**：以資料包中的陷阱讓學員找到至少兩項，講師版另有答案提示。

## 投影片 20｜小組實作

**投影片文字**
- 選 A1、A2 或 A3
- 先盤點資料，再選 skill/context
- 讓 Agent 在 output 產出文件與／或工作表
- 展示來源、待確認項及一項修訂

**講者備註／操作**：75 分鐘實作；A1 建議 `tw-edu-school-curriculum-plan`／`tw-edu-school-document`，A2 建議 `tw-edu-meeting-facilitator`，A3 建議 `tw-edu-school-document`／`tw-edu-parent-communication`。評量重流程、可追溯和人工覆核，不比較誰的文字最長。

## 投影片 21｜成果驗收規準

**投影片文字**
- 內容正確且有來源
- 欄位完整、格式可用
- 矛盾和缺漏有揭露
- 原始資料未被覆寫
- 對外動作仍由承辦人核准

**講者備註／操作**：用 rubric 做同儕互評並要求每組展示一項 Agent 不該自行決定的事情。

## 投影片 22｜銜接行政應用（二）

**投影片文字**
- 下一堂沿用 workspace、skills、context 和追蹤格式
- 加入問卷／庫存分析與主管簡報
- 從單一任務走向跨文件工作流
- 再討論觸發條件、排程和核准點

**講者備註／操作**：課後任務：選一個低風險行政任務，記錄輸入資料夾、使用 skill/context、輸出和驗收問題。
