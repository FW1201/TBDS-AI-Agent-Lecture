# AI Agent 行政自動化思維應用初探（二）｜簡報內容大綱

> 可直接交給 Claude 生成簡報。請將「講者備註／操作」置於講者備註。建議 3 小時、約 24 頁。假設學員已完成行政（一），本堂沿用台灣高中課發會／學務活動情境、同一 workspace 與資料包。

## 投影片 1｜封面

**投影片文字**：AI Agent 行政自動化思維應用初探（二）｜從資料整理到分析、簡報與可重複工作流｜Codex 實作課

**講者備註／操作**：回顧前堂的單次文件流程，今天擴展到多檔案、多格式和可重複任務。

## 投影片 2｜由行政（一）接續

**投影片文字**
- 已有 workspace、skill/context 和案例資料夾
- 已讓 Agent 整理文件及追蹤表
- 今天沿用這些輸出，建立分析和簡報
- 核心仍是可追溯、可覆核、有核准點

**講者備註／操作**：請學員打開前堂產出，確認輸入、輸出和待確認清單都在專案內。

## 投影片 3｜多步驟工作流長什麼樣

**投影片文字**
- 讀取來源資料
- 檢查欄位和資料品質
- 計算摘要與例外
- 生成報告／簡報草稿
- 人工覆核後才交付或觸發後續工作

**講者備註／操作**：畫出流程，標示每一步輸入／輸出和停下來詢問的條件。

## 投影片 4｜Harness：讓多步驟仍可控

**投影片文字**
- workspace 限定工作範圍
- skills 提供步驟和檢查
- context 提供校務定義和規則
- 工具提供文件、試算表、簡報操作
- 人工核准控制外部影響

**講者備註／操作**：回顧 Prompt／Context／Harness；請學員指出本堂各自在哪裡。

## 投影片 5｜從 GitHub 更新資源包

**投影片文字**
- 查看資源來源、版本和變更內容
- 新增 skill 前檢查功能、依賴和限制
- context 更新需確認生效日期及適用範圍
- 保留變更紀錄，避免新舊規則混用

**講者備註／操作**：展示本課程 `resources/manifest.md` 記錄的 v5.0.1 commit；以版本紀錄說明如何新增版本、檢查變更和授權，不覆寫既有上游原件。

## 投影片 6｜案例 A4：校訂課程成果交流回饋

**投影片文字**
- 輸入：合成親師回饋、欄位說明、成果交流活動背景 context
- 先檢查缺漏、重複、尺度和分母
- 再用 Sheets 整理摘要與圖表
- 輸出 Document 改善報告和 Presentation 草稿

**講者備註／操作**：資料包含空白列、重複回覆和尺度混用；先讓 Agent 盤點問題，不直接下結論。

## 投影片 7｜先問資料是否能分析

**投影片文字**
- 每列代表什麼？是否有重複？
- 空白和「未填」如何處理？
- 評分尺度是否一致？
- 回覆數能否代表整體？
- 哪些結論目前不能支持？

**講者備註／操作**：要求 Agent 在正式計算前產出 data quality memo，列明採用及排除規則供承辦人確認。

## 投影片 8｜Sheets：保留計算路徑

**投影片文字**
- 保留原始資料副本
- 明確定義欄位和清理規則
- 公式／摘要可以重算
- 圖表標示樣本數與單位
- 不把相關性寫成因果

**講者備註／操作**：展示試算表原始、清理、摘要三個工作表的分工；用一個指標核對公式。

## 投影片 9｜讓 Agent 解釋它的分析

**投影片文字**
- 要求列出篩選條件和公式
- 每個結論指出對應欄位／工作表
- 說明缺漏可能造成的偏差
- 對樣本不足的結論標記限制

**講者備註／操作**：追問 Agent：「這個比例分母是什麼？排除了哪些列？請指出工作表位置。」

## 投影片 10｜從分析轉成可採取的建議

**投影片文字**
- 觀察：資料實際顯示什麼
- 解釋：可能原因及不確定性
- 建議：可測試的改善行動
- 指標：如何確認改善是否發生

**講者備註／操作**：用表格把觀察、推論、建議分欄，避免把模型猜測包裝成事實。

## 投影片 11｜Document 報告：一頁看懂但可追溯

**投影片文字**
- 目的與資料範圍
- 三項主要發現及樣本數
- 限制、假設與待確認事項
- 建議行動、負責角色和追蹤日期
- 附上工作表來源

**講者備註／操作**：讓 Agent 依已核對的 Sheets 摘要建立報告草稿，不新增未經驗證的數字。

## 投影片 12｜Presentation：主管簡報不是換格式而已

**投影片文字**
- 一頁一個訊息
- 結論先行，證據跟上
- 圖表口徑和報告一致
- 需決策事項明確標示
- 備註保留來源和限制

**講者備註／操作**：可搭配 `tw-edu-slides-creator` 草擬教學簡報，再以本課 Presentation 工作流整理主管簡報；展示每張投影片如何回到追蹤工作表與摘要文件的來源。

## 投影片 13｜案例 A5：視聽教室與活動設備盤點

**投影片文字**
- 輸入：合成視聽設備、教室盤點表、活動需求
- Agent 找重複項、低庫存、缺少日期和異常狀態
- 產出 Sheets 異常清單和 Document 建議草稿
- 承辦人核實現場數量與採購程序

**講者備註／操作**：可用 `tw-edu-school-document` 整理差異說明；讓小組決定優先排序規則，要求 Agent 明寫規則，不將判斷隱藏在描述中。

## 投影片 14｜案例 A6：課發會與學務工作月報

**投影片文字**
- 沿用課發會決議追蹤和成果交流工作表
- 彙整完成、進行中、逾期和待決策事項
- 產出月報試算表、主管簡報、摘要文件
- 每項狀態需指向來源和更新日期

**講者備註／操作**：展示同一資料如何轉為三種格式；提醒不能因過期資料而判定某事項仍未完成。

## 投影片 15｜Agent 跨資料夾操作示範

**投影片文字**
- 讀取指定 input 和既有輸出
- 先回報檔案地圖與預計步驟
- 建立版本化輸出，不覆蓋原始檔
- 完成後列出新增／修改檔案和未解問題

**講者備註／操作**：實際演示 Agent 在專案資料夾搜尋、多檔案對照、建立工作表／報告／簡報草稿。

## 投影片 16｜建立可重複的專案模板

**投影片文字**
- 固定 input、context、output 位置
- 固定命名和版本方式
- 固定分析欄位與覆核問題
- 將通用步驟封裝成 skill
- 每次執行記錄日期、資料範圍和操作者

**講者備註／操作**：讓各組把一堂課中重複用到的步驟整理成 skill 草稿，但不把特定案例假設寫成通用規則。

## 投影片 17｜Connectors／MCP：資料來源的延伸

**投影片文字**
- 連接器可減少人工搬檔，但擴大資料可見範圍
- 明確指出需要讀取的服務和資料夾
- 優先唯讀；寫入採草稿或核准流程
- 連線失敗時切回核准的檔案匯出

**講者備註／操作**：依實際已授權工具展示；不要求學員為課堂連接未核准服務。

## 投影片 18｜Runtime／Hooks／排程基本設計

**投影片文字**
- 觸發：時間、檔案更新或人工啟動
- 前置檢查：資料完整、版本符合、範圍正確
- 執行：只建立草稿或分析結果
- 停止：發現矛盾、敏感資料或異常就交由人員
- 記錄：輸入、時間、結果、覆核者

**講者備註／操作**：用月度工作彙整設計流程圖；實際 hooks／排程是否可操作依環境版本確認。

## 投影片 19｜從自動草稿到核准動作

**投影片文字**
- 可自動：整理、分類、分析、草擬
- 先核准：寄送、正式登錄、刪除、採購、權限變更
- 設定停止條件和回報方式
- 不因「排程已成功」推定內容正確

**講者備註／操作**：請學員為一個工作流圈出所有需要人員點頭的位置。

## 投影片 20｜小組實作：完整行政工作流

**投影片文字**
- 選 A4、A5 或 A6
- 找到並說明 skill/context
- 讓 Agent 盤點、分析並產出兩種格式
- 做一次人工核對和一次定點修訂
- 展示工作流的停止／核准條件

**講者備註／操作**：75 分鐘；至少要展示一個資料品質問題和一個產出修訂。

## 投影片 21｜檢查簡報與報告的數字

**投影片文字**
- 數字能否回算？
- 分母、期間和單位一致嗎？
- 圖表是否誤導？
- 文字有沒有超出資料能支持的範圍？
- 來源檔是否仍在專案中？

**講者備註／操作**：用抽查方式從投影片挑一項數字回到工作表重算。

## 投影片 22｜小組成果評量

**投影片文字**
- 完成目標：輸出符合任務需求
- 可追溯：來源、規則、版本清楚
- 安全：資料與操作權限適當
- 穩健：能處理缺漏和矛盾
- 可交接：他人能重複執行和覆核

**講者備註／操作**：進行同儕檢查並讓每組說明一項應停止自動化的情況。

## 投影片 23｜帶回工作現場前的檢查

**投影片文字**
- 先從低風險、可逆、可覆核任務開始
- 用合成或經核准資料試跑
- 清楚標出 Agent 產出和人工核定
- 設計失敗回報、版本紀錄和停止條件

**講者備註／操作**：請每位學員寫下一個可先試行的任務和一個不可自動化的決定。

## 投影片 24｜收束：讓工作流可重複，不讓責任消失

**投影片文字**
- 資源包提供 skill/context
- Workspace 提供工作邊界
- Agent 操作檔案並產出多格式草稿
- 人員核驗事實、決定並核准動作

**講者備註／操作**：課後任務：把一個低風險月度工作整理成可重複的專案模板，附上停止條件和驗收表。
