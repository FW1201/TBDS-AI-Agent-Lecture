# 台灣國高中情境來源與轉用原則

## 官方參考入口

教材情境參照台灣十二年國民基本教育的課程架構與國高中常見校務工作，授課前請從官方網站確認現行版本及領域文件：

- 國家教育研究院（課程綱要及教育研究資料入口）：<https://www.naer.edu.tw/>
- 教育部國民及學前教育署（中小學教育政策與行政資訊入口）：<https://www.k12ea.gov.tw/>
- 教育部（課程、教育政策與法規資訊入口）：<https://www.edu.tw/>

建議查閱文件名稱：十二年國民基本教育課程綱要總綱、國中社會領域課綱、普通型高中地理課綱、國語文領域課綱，以及授課學校公開的校訂課程計畫和課發會流程。不同學年度和學校的表單、時程、選課規則可能不同，應以最新官方及校內版本為準。

## 本次素材轉用狀態

本課程匯入的 `skills/upstream/tw-edu-skills/shared/curriculum/references/curriculum/` 含上游提供的課綱資料快照與 `snapshot-manifest.json`（上游標示快照日期 2026-09-08，並提供檔案來源及 SHA256）。本次沒有另行從官方網站下載並逐頁核驗原始課綱，因此快照僅供課堂搜尋、理解結構和演練 Agent 工作流程，不作正式引用依據。授課或正式產出前，仍須從官方入口核對現行課綱的版本、條文、代碼和頁碼。

學生資料包以台灣國高中常見教學及校務工作流程設計合成案例，文件標示為模擬；沒有冒充真實學校紀錄、個人資料、評量結果或未經核實的法規要求。上游技能中的法規主張亦須依其 `CITATIONS.md` 所列狀態和日期再查官方來源。

後續若有可用的官方素材，應先確認公開授權與重用條件，只擷取完成教學所需的段落，記錄文件標題、發布機關、版本／日期、URL、授權和轉用方式。真實學生作品、會議紀錄、家長回覆和校務資料不應直接放入學生包；需要呈現真實資料結構時，請以合成資料替換身分與敏感欄位。

## 合成資料標示

- 每個學生資料文件標註「課程模擬文件」或「合成值」。
- 情境可以仿照真實工作流程，但虛構的日期、角色和決議不可說成真實案例。
- 數據練習應明確區分真實公開統計、模擬值和模型生成內容。
- 若由 Agent 轉換官方公開文件，產出保留來源、版本、頁碼／段落及轉換紀錄。
