# 講師手冊

## 開課前

### 一週前

- 確認 Codex 版本、檔案讀寫能力、Connector/MCP 可用性和學員登入狀況。
- 取得資源包 GitHub URL；記錄 commit、版本、授權與離線備份位置。
- 檢查學生 ZIP 可下載、解壓縮，且講師解讀文件不在 ZIP 中。
- 確認電腦上有可讀寫的練習 workspace；每組至少一台裝置。
- 若不支援原生 DOCX/XLSX/PPTX 編輯，備妥可編輯文字／CSV 的替代工作流。

### 開課當日

- 使用虛構資料，螢幕分享前關閉個人信箱、真實雲端硬碟和含個資的視窗。
- 把學生包解壓到各組自己的資料夾，避免共用輸出互相覆寫。
- 講師先確認環境無預先生成的答案檔，避免學生看到講師提示。
- 示範任務先要求 Agent 盤點和提問，再同意它建立輸出。

## 故障與備援

- **GitHub 無法連線：**使用課前下載且記錄相同 commit 的資源副本；記錄離線原因，不要求學員自行輸入 token。
- **Agent 未能讀某格式：**轉存成 PDF／DOCX／CSV 等核准副本，保留來源檔；請 Agent 說明未讀到的資料，不假裝成功。
- **Agent 自行假設：**要求列出假設和來源；若影響正式事項，停止生成並請承辦人決定。
- **格式工具不存在：**輸出 Markdown／CSV 草稿，讓學員完成同一內容流程；簡報檔可交由講師另行生成。
- **工具開始改寫原檔：**停止操作，檢查版本控制／備份，改設新輸出目錄後再重跑。
