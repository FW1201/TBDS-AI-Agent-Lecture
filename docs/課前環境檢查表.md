# 課前環境檢查表

## 講師檢查

- [ ] 學員能登入 Codex，並理解目前 workspace 根目錄。
- [ ] 確認當前 Codex 對 DOCX、XLSX、PDF、CSV 和資料夾操作的實際能力。
- [ ] 確認實際可用的 Connectors/MCP；只列已測試項目。
- [ ] 確認 skills 的載入位置、啟用方式和版本；若尚未提供 tw-edu skills，使用本課程的任務卡演練 skill 概念。
- [ ] Runtime/hooks/排程以環境支援狀況為準；未測試的功能只做設計練習。
- [ ] 從課程 GitHub 資源包確認來源 URL、commit、授權和更新日期。
- [ ] 學生 ZIP 可正常解壓；講師解讀檔不在 ZIP。
- [ ] 每組有獨立工作副本和 output 目錄。
- [ ] 預備離線資源包和純文字／CSV 備援材料。

## 學員開課檢查

- [ ] 我知道本次任務的 input、output 和允許讀寫範圍。
- [ ] 我知道 Agent 用到的 skill/context 文件及來源。
- [ ] 我確認沒有把真實學生或同仁個資、帳密、未核准校務資料放進 workspace。
- [ ] 我先要求 Agent 盤點、列來源和不確定處，再要求它編輯。
- [ ] 我要求建立新檔案，不覆蓋原始來源。
- [ ] 我知道哪些動作需要人工核准。
