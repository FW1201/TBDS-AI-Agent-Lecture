# 課程地圖與學習成果

## 課程定位

本課程以 Codex 作為 Agent 操作介面，從檔案型專案開始，帶學員把 GitHub 資源包中的 skill、context 和案例資料放入 workspace，再由 Agent 讀取、整理、編輯與產出可覆核成果。教學應用內容開兩班；行政應用（一）（二）是連續課程。

## 課前條件

- 學員可使用學校核准的 Codex 環境，並可開啟課程 workspace。
- 講師提供課程 GitHub 資源包位置；若外網或權限受限，課前提供同版本離線副本。
- 學員會操作一般資料夾與文件即可，無須寫程式。
- 全程使用資料包中的虛構案例；不以真實學生、家庭或校務資料練習。

| 3 | AI Agent 行政自動化思維應用初探（一） | 準備散落行政情境資料及公告／會議 skill/context | 學員能盤點矛盾來源，產出公告或會議追蹤文件，保留待核事項和來源 | 為一項低風險行政工作寫出輸入、步驟、輸出、檢核點 |

## 能力階梯

1. **互動：**把需求拆成 Prompt，說清楚目標、對象、限制和格式。
2. **脈絡：**在 Context 中挑選可信文件，識別來源日期、版本和衝突。
3. **專案：**建立 workspace，區分原始資源、輸入、輸出和交付物。
4. **委派：**讓 Agent 先盤點與回報計畫，再在限定範圍內讀寫檔案。
5. **擴充：**使用 Connectors/MCP 和 skills，理解授權和資料流。
6. **自動化：**設計 runtime/hooks/排程的觸發、停止、紀錄和人工核准點。
7. **驗收：**核對事實、計算、來源、隱私、內容適切性和對外影響。

## 課程版本一致性

教學 A、B 班共用同一份簡報大綱、任務卡、資料包和評分規準。可依 A 班的授課時間調整講師說明，但不得改成不同的核心作業或評分門檻，以維持兩班學習成果可比較。
