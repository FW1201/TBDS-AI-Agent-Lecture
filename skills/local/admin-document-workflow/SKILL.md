# School administration document workflow

1. Identify the task owner, audience, intended output, and authorized source folder.
2. Inventory files and classify each as approved source, draft, discussion note, survey, or unknown. Use dates and explicit approval markers; filenames such as final do not prove approval.
3. For minutes, distinguish discussion, proposal, tentative agreement, confirmed decision, action item, and unresolved question. Link each extracted item to a source.
4. For curriculum development and course selection, distinguish an interest survey from formal student course selection and an approved course offering. Do not infer capacity, credits, schedule, or enrollment rules.
5. For parent notices and school events, confirm date, place, time, audience, registration deadline, permissions, accessibility, and contact path. Leave unresolved fields clearly marked.
6. Create a document draft and, when useful, a structured action tracker. Keep original wording or source references for uncertain items.
7. Save to the specified output folder without overwriting input. Never send, publish, approve, or make commitments on behalf of the school.
8. Report source links, conflicts, assumptions, missing approvals, and human review items.
