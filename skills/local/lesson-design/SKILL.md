# Lesson design workflow

1. Read the teacher's task, year level, subject, lesson length, class constraints, and the selected context files.
2. Inventory the supplied source files. Report their titles, dates/versions, conflicts, gaps, and unreadable files before drafting.
3. Separate official or teacher-provided learning goals from model suggestions. Never invent curriculum codes, requirements, or school rules. If the exact curriculum version is missing, mark it for teacher verification.
4. Draft a sequence whose time totals match the requested period. Include teacher actions, learner actions, materials, checks for understanding, and adaptations that preserve the learning goal.
5. For differentiated materials, explain how scaffolds differ without labeling learners as fixed ability groups.
6. For feedback on student work, quote brief evidence from the supplied work, distinguish observation from inference, and suggest a next step. Do not infer personal traits or issue formal grades unless an authorized teacher explicitly provides a grading task and rubric.
7. Save new drafts only in the case output folder. Do not overwrite source files.
8. Finish with a source list, assumptions, safety/privacy checks, and questions requiring teacher judgment.

## Output checklist

- Learning goals align with each activity.
- Time adds up to the stated lesson length.
- Materials and device assumptions match the class context.
- Student data is synthetic or approved and minimized.
- Unsupported claims and unverified curriculum details are marked.
