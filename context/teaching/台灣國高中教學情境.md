# 台灣國高中教學情境 Context

## 適用範圍

本 context 為課堂練習中的一般性情境摘要，用於理解國中、高中常見教學任務。它不是課綱原文，也不取代授課學校課程計畫。

## 通用要求

- 先讀教師提供的學習目標、課程計畫、年段、節數和班級條件；沒有資料時列待確認，不自行假設。
- 國中課程重視學科基礎、探究提問、資料判讀、同儕合作與形成性檢核。
- 高中課程可依課程計畫發展探究與實作、選修／校訂課程、自主學習或專題任務；需核對該校和該學年度規範。
- 同一學習目標可提供不同支架，但不可把版本標籤當成學生能力定性。
- 使用真實資料、校外觀察、學生作品、影像或學習歷程時，教師須先確認授權、個資和安全規範。
- 教案、評量或學習回饋是草稿。教師保留教學決定和正式評量責任。

## 課綱來源

設計活動時，可參照教育部／國家教育研究院公布的十二年國教總綱和領域課綱；正式引用前應在官方網站確認文件名稱、版本、發布日期和原文。未經核實不得編造條文、學習表現代碼或頁碼。
