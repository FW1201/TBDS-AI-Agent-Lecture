# 台灣國高中校務流程與詞彙 Context

以下是用於情境辨識的通用說明，不構成行政規則。各校組織、表單、權限、時程和審議程序有差異，Agent 不得據此宣稱校內事項已核定。

| 詞彙 | 本課程中的情境含義 | Agent 的處理方式 |
|---|---|---|
| 課程發展委員會／課發會 | 討論學校課程規劃、校訂課程和相關事項的校內會議情境 | 分清提案、討論、暫議、決議和待確認；須依核定紀錄 |
| 校訂選修／多元選修 | 高中課程規劃與選課情境 | 意向調查不是正式選課；不可自行推定開課、學分或學生志願 |
| 校務會議／行政會議 | 校內資訊討論與行政協調情境 | 草稿和個人意見不可改寫成正式決議 |
| 學務處／教務處／總務處 | 常見校務工作角色 | 只有來源明確指派時才填承辦角色，不猜測個人責任 |
| 親師溝通／成果交流 | 通知、活動、作品展示和回饋情境 | 先確認日期、場地、作品授權、攝影告知及對外核准 |
| 學習歷程／學生作品 | 學習反思與成果呈現情境 | 最小化資料；合成或去識別內容；不得把 Agent 回饋當正式成績 |

所有本課程文件中的校名、角色、資料和決議均為虛構。正式工作需以該校有效版本和有權責人員確認為準。
