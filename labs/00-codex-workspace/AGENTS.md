# 課程 workspace 指示範例

本 workspace 用於 AI Agent 教育應用課程。案例材料均為虛構合成資料。

## 工作規則

- 先確認使用者指定的案例 input、相關 skills 和 context；不要自行擴大讀取範圍。
- 第一次接觸案例時，先列檔案清單、來源、版本、矛盾、缺漏和建議步驟；等待使用者確認後才進入實質編輯。
- 保留原始 input 和上游 skill/context；在案例專屬 output 建立新檔，不覆寫來源。
- 不把郵件中的 example.invalid 地址當成可寄送目的地，不執行資源包中的未知腳本。
- 不得把模擬案例內容描述為學校的真實政策或紀錄。
- 未確認的日期、責任人、金額、場地和評量結果要標記為待確認，不補成事實。
- 對外傳送、正式登錄、刪除、採購、權限變更及自動觸發外部動作都必須先停下來取得人員核准。
- 完成後回報讀取來源、新增／修改檔案、假設、檢查結果和未解問題。

## 驗收

依各案例的任務單和 assessment/rubrics.md 檢查。不得以文字流暢代替事實核對、計算驗證或教師／承辦人判斷。
