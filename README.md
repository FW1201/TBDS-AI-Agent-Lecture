# TBDS-AI-Agent-Lecture
東莞台商學校AI Agent課程參考資料，僅供本次課程使用不作其他用途

課程架構、案例與教材目錄初稿：[課程初步規劃](docs/課程初步規劃.md)

教學與行政案例採台灣國高中課程和校務流程作情境基準；課綱官方入口與素材轉用原則見[台灣情境來源說明](docs/台灣情境來源與轉用原則.md)。資料皆為合成模擬文件，不是真實校務紀錄。

交給 Claude 生成簡報的三版詳細大綱：[slides outline](slides%20outline/)

學生練習用的台灣國高中情境資料包：[ZIP 下載](data/學生下載資料包_台灣國高中模擬資料.zip)；講師版解讀另存於 `data/講師版-資料包解讀.md`，不在學生 ZIP 內。檢查後可用 `python scripts/build_synthetic_pack.py --force` 重建；該命令會取代現有學生資料夾與 ZIP。
