# Runtime／Hooks／排程工作流設計

本目錄提供設計練習，不預設目前 Codex 版本已開通特定 hook 或排程介面，也不包含會自動寄信、寫入正式系統或修改真實校務資料的執行設定。講師需先確認環境版本及權限，再決定是否做實際演示。

## 課程示例：每月課發會行動追蹤草稿

1. **觸發：**承辦人手動啟動，或由已核准環境設定的月初工作提醒啟動。
2. **前置檢查：**確認只讀取指定月份、指定 input，追蹤表有更新日期，文件不含不應處理的個人資料。
3. **讀取：**只讀已核准會議紀錄、行動表和本地 context。
4. **產出：**在新 output 建立進度摘要和待確認清單。
5. **停止條件：**會議紀錄未核定、狀態來源衝突、責任人缺漏、資料疑似含敏感資訊或來源過期時停止並請承辦人處理。
6. **人工核准：**承辦人核對數字與狀態後，才可複製到正式月報；寄送或登錄另需權責人員執行。
7. **紀錄：**保存執行日期、讀取來源、產出檔、錯誤和核准角色，不保存秘密值。
