# 學員交付檢核

提交前每組確認：

- [ ] 有明確的任務 Prompt，包含目標、條件、格式和停止條件。
- [ ] 有使用的 skill/context 名稱、版本和來源。
- [ ] Agent 先盤點資料；原始資料未被覆寫。
- [ ] 至少一項矛盾或缺漏被揭露並保留待確認。
- [ ] 文件、表格或簡報成果可追溯到來源。
- [ ] 數字有公式／分母／單位；內容有適切性檢查。
- [ ] 有 Agent 操作摘要及人工修改記錄。
- [ ] 對外動作仍需人工核准。

## 小組交付目錄

```text
output/<組別>/<案例>/
├── 來源清單.md
├── Agent操作摘要.md
├── 草稿文件.docx 或 .md
├── 追蹤／分析工作表.xlsx 或 .csv
├── 簡報大綱.md（需要時）
└── 待確認事項.md
```
