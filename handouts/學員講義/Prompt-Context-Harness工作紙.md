# 學員講義｜Prompt、Context、Harness 工作紙

## 同一個需求，逐層補足

**模糊要求：**「幫我整理這次活動。」

### Prompt：任務說明

- 你要 Agent 做什麼？
- 目標讀者是誰？
- 交付物是什麼格式？
- 哪些條件不能違反？
- 什麼情況要先停下來問？

### Context：工作依據

- 哪些文件是已核准來源？
- 有哪些版本、日期或詞彙定義？
- 哪些背景是必要的？
- 哪些資料不應提供？

### Harness：執行邊界

- Agent 的工作目錄是哪裡？
- 哪些資料夾可以讀？
- 哪裡可以寫新檔？
- 是否要先列計畫／取得核准？
- 如何記錄修改、停止和回退？

## 改寫練習

請用一個學生包案例，把模糊要求改成可執行工作指令。以「來源、限制、輸出、驗收」四欄互相檢查。完成後交換同學的指令，指出哪一處仍可能讓 Agent 自行猜測。
