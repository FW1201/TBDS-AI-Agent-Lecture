# 學員講義｜Agent 檔案操作與覆核清單

## 開始前

- [ ] 我在正確的 workspace 和案例資料夾。
- [ ] input 原始檔保留；Agent 的新檔輸出到獨立 output。
- [ ] 我已指定要使用的 skill/context 和允許範圍。
- [ ] 我使用合成或核准資料，沒有個資、帳密或敏感校務資料。

## Agent 盤點後

- [ ] 它列出檔案名、格式和可用日期。
- [ ] 它指出重複、舊版、矛盾、缺值或讀取失敗。
- [ ] 它說明依據，並詢問尚未核定的事項。
- [ ] 它的修改計畫沒有覆寫或移除原始資料。

## 交付前

- [ ] 文件日期、名稱、角色、地點、數量有來源。
- [ ] 表格欄位、公式、分母、單位和缺失規則一致。
- [ ] 教學內容符合目標、年級、時間、可用設備與安全條件。
- [ ] 簡報每項結論可回查來源。
- [ ] Agent 的假設與不確定處清楚標示。
- [ ] 對外寄送、正式登錄、刪除、採購或權限動作仍由人員核准。
